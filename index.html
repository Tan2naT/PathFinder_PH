Permissions & Tips

Security: Ensure you are using HTTPS. Browsers block location access on insecure connections.

Geolocation: Allow high-accuracy location access when prompted so PathFinder PH can track your live movement.

Audio Sound: Web browsers require user interaction before playing alarm sounds. Click "ARM LOCATION ALARM" to grant sound approval.

Vibration: Vibrations work on compatible mobile devices (Android).

Simulation Mode: Use the "Simulate" button at the top to test the app without physically moving around!
